# アフィリ・ネタ工房（仮）会社設計

| 項目 | 内容 |
|---|---|
| 目的 | 副業のアフィリエイトを小さく試す。記事ネタ出しをAI社員に任せる練習 |
| 業務 | 読者の悩み別に、アフィリエイト記事ネタを3案つくる |
| 利用者 | 商品に興味を持っている人（比較や選び方を探している人） |
| 入力 | 架空の商品ジャンル（依頼時に本人が渡す）。実在情報・個人情報は使わない |
| 成果物 | 記事ネタ3案（HTML、必要に応じテキスト控え） |
| 分担 | リーダー＋ idea-planner → article-drafter → claim-checker |
| 品質 | すぐ使える具体性。事実の捏造をしない、推測を区別する、依頼に答える |
| 確認 | 材料不足や大きな判断（実在商品、広告表記など）があるとき相談 |
| 頻度 | まず今回1回（定期実行なし） |
| 初回依頼 | 「私が架空の商品ジャンルを渡したら、読者の悩みごとの切り口で、アフィリエイト記事ネタを3案出して」 |

実務は、本人が依頼するまで開始しません。
